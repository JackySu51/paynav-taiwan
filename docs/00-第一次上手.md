# 00 ｜第一次上手（Mac，完全沒寫過程式也能跟著做）

這份文件從「你的 Mac 什麼都沒裝」開始，做到「在瀏覽器看到 App」。
每一步都會告訴你**在哪裡做**、**打什麼字**、**看到什麼才算成功**。

預估時間：25 分鐘，其中 15 分鐘在等安裝。

---

## 你會用到的兩個工具

| 工具 | 是什麼 | 怎麼打開 |
| --- | --- | --- |
| **終端機（Terminal）** | 用打字下指令的視窗，所有安裝與啟動都在這裡 | 按 `⌘ + 空白鍵`，輸入 `終端機` 或 `Terminal`，按 Enter |
| **VS Code** | 改程式碼用的編輯器（像 Word，但給程式用） | 下一節會裝 |

> 看到「在終端機執行」時，就是把那行字複製貼進終端機視窗，按 Enter。
> 指令跑完通常會回到一行結尾是 `$` 或 `%` 的狀態，代表可以打下一行了。

---

## 步驟 1：安裝 Node.js

這個 App 需要 Node.js 才能跑（版本要 20 以上）。

1. 打開瀏覽器到 <https://nodejs.org/>
2. 下載左邊那顆 **LTS**（長期支援版）按鈕的 `.pkg` 檔
3. 點兩下安裝，一路按「繼續」到完成

**確認裝好了**：打開終端機，執行

```bash
node -v
```

看到類似 `v20.18.0` 或更高的數字就對了。如果顯示 `command not found`，把終端機關掉重開再試一次。

---

## 步驟 2：安裝 VS Code

1. 到 <https://code.visualstudio.com/> 下載 Mac 版
2. 解壓縮後把 `Visual Studio Code` 拖進「應用程式」資料夾

（這步驟不裝也能跑 App，但之後要改回饋規則會很痛苦，建議裝。）

---

## 步驟 3：把專案放到你的電腦

假設你要放在「文件」資料夾裡。在終端機執行：

```bash
cd ~/Documents
```

`cd` 是「切換到某個資料夾」，`~` 代表你的家目錄。這行之後，你人就在 `/Users/你的名字/Documents`。

接著把下載到的 `setup-paynav.sh` 放進來（從「下載項目」拖到「文件」資料夾即可），然後執行：

```bash
bash setup-paynav.sh
```

你會看到一連串 `· src/App.tsx` 之類的訊息，最後印出 `✅ 完成，共 40 個檔案。`

現在 `~/Documents/paynav-taiwan/` 就是你的專案資料夾。用 Finder 打開它可以看到 `src`、`public` 這些資料夾。

---

## 步驟 4：安裝套件

進到專案資料夾，安裝它需要的程式庫：

```bash
cd ~/Documents/paynav-taiwan
npm install
```

第一次會跑 30 秒到 2 分鐘，畫面上會有一堆進度條，出現 `added 412 packages` 之類的訊息就成功了。
中間可能出現黃色 `warn` 字樣，那是提醒不是錯誤，可以忽略。

> 這一步會產生一個很大的 `node_modules` 資料夾，那是套件本體。**不要手動去動它**，也不要上傳到 GitHub（`.gitignore` 已經幫你擋掉了）。

---

## 步驟 5：跑起來看看

```bash
npm run dev
```

終端機會印出：

```
  ➜  Local:   http://localhost:5173/
```

按住 `⌘` 點那個網址，或自己複製到瀏覽器打開。你應該會看到深色的「支付導航」畫面。

**這時候終端機不能關**，它正在幫你跑網站。要停止的話按 `Control + C`。

### 第一次打開該做什麼

1. 右上角點「0 張卡」→ 勾選你真的有的信用卡 → 按「完成」
2. 回到主畫面，就會看到依回饋率排序的支付建議
3. 切到下面「載具」分頁，輸入你的手機條碼（例如 `/AB1234+`），條碼會即時畫出來

> **定位在電腦上會失敗是正常的**，因為 `localhost` 沒有真實 GPS。點頂部的店家列可以手動選通路。手機實測方式看步驟 7。

## 步驟 6：改東西（最常改的兩個檔案）

用 VS Code 打開專案資料夾（VS Code → File → Open Folder → 選 `paynav-taiwan`）。

**改回饋規則**：`public/data/rules.json`

```jsonc
{
  "payment_method": "jkopay",      // 哪個支付：jkopay/linepay/pxpayplus/easywallet/icashpay/taiwanpay/apple_pay/physical
  "channels": ["seven_eleven"],     // 哪些通路，全部適用就寫 ["all"]
  "base_reward_pct": 1,             // 基本回饋 %
  "extra_reward_pct": 4,            // 加碼回饋 %
  "cap_amount_monthly": 300,        // 每月回饋上限，沒有上限就寫 null
  "note": "需登錄活動",              // 顯示在卡片上的備註
  "valid_until": "2026-12-31"       // 活動到期日，到期前 30 天會自動提醒你
}
```

**改門市與通路**：`public/data/stores.json`
`channels` 是手動下拉選單的清單，`stores` 是有座標的門市點位。

存檔後**不用重開**，瀏覽器會自己更新。

改完建議跑一次檢查，確認沒打錯字：

```bash
npm run check:rules
```

看到 `✅ 全部正常` 就沒問題。如果它說某個通路代號找不到，代表 `rules.json` 裡的 `channels` 寫了 `stores.json` 沒有的名字。

## 步驟 7：在自己的 iPhone 上測試

定位和「加入主畫面」都需要 HTTPS，用區網 IP 直接連是拿不到 GPS 的。最快的做法是先部署上線（看下一份文件），部署後直接用手機開網址。

真的想在本機測，可以開一條臨時的 HTTPS 通道。新開一個終端機分頁（`⌘ + T`），保持 `npm run dev` 那個分頁繼續跑，然後：

```bash
npx cloudflared tunnel --url http://localhost:5173
```

它會給你一個 `https://隨機字串.trycloudflare.com` 網址，用手機 Safari 打開就能測定位。關掉終端機網址就失效。

## 常見狀況

| 畫面訊息 | 意思 | 怎麼解 |
| --- | --- | --- |
| `command not found: npm` | Node.js 沒裝好 | 重做步驟 1，裝完關掉終端機重開 |
| `EADDRINUSE: address already in use :::5173` | 已經有一個 `npm run dev` 在跑 | 到舊的終端機分頁按 `Control + C`，或改用 `npm run dev -- --port 5174` |
| 畫面全白 | 通常是 JSON 打錯字 | 在瀏覽器按 `⌘ + Option + I` 開開發者工具看紅字，或跑 `npm run check:rules` |
| `規則庫沒讀到` | `public/data/` 的 JSON 格式壞了 | 跑 `npm run check:rules` 看是哪一行 |
| 定位一直失敗 | localhost 沒有 GPS | 正常現象，手動選通路，或用步驟 7 的通道測 |
