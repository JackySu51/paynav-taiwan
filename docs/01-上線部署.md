# 01 ｜上線部署（GitHub → Cloudflare Pages）

目標：把專案放上 GitHub，讓它每次改動都自動部署到網路上，手機打開就能用。

預估時間：40 分鐘（第一次），之後每次更新只要「存檔 → 推上去」。

---

## 為什麼是這個組合

| 角色 | 誰負責 | 為什麼 |
| --- | --- | --- |
| 存程式碼 | GitHub | 免費、有版本紀錄、改壞了可以退回去 |
| 自動打包部署 | GitHub Actions | 你推程式碼，它自動幫你 build 並上傳 |
| 放網站 | Cloudflare Pages | 免費、自動 HTTPS、全球 CDN，台灣速度快 |
| 放會變動的資料 | Cloudflare R2 | 改回饋規則不用重新部署整個網站 |
| 跑定時任務 | GitHub Actions | 每天檢查回饋規則有沒有過期 |

**Cloudflare Pages 和 GitHub Pages 選一個就好。** 建議 Pages，因為它和 R2、Workers 在同一個後台，之後串起來最省事。GitHub Pages 的做法附在最後。

---

## 步驟 1：把程式碼推上 GitHub

### 1-1 註冊與建立 repository

1. 到 <https://github.com/> 註冊（有帳號就跳過）
2. 右上角 `+` → **New repository**
3. Repository name 填 `paynav-taiwan`
4. 選 **Private**（之後想公開再改）
5. **下面的 Add README、.gitignore、license 全部不要勾**
6. 按 **Create repository**

建好後畫面會給你一個網址，長得像 `https://github.com/你的帳號/paynav-taiwan.git`，等下要用。

### 1-2 設定 Git 身分（只要做一次）

**先確認 Mac 有沒有裝 git。** 新的 Mac 預設是沒有的：

```bash
git --version
```

- 看到 `git version 2.x.x` → 有裝，繼續下一步
- 跳出「需要安裝命令列開發者工具」的視窗 → 按**安裝**，等 5-10 分鐘裝完再回來
- 顯示 `command not found` → 執行 `xcode-select --install`，照著視窗裝

裝好後執行下面兩行，把引號裡換成你自己的資料：

```bash
git config --global user.name "你的 GitHub 帳號"
git config --global user.email "你註冊 GitHub 用的 email"
```

**確認設定成功**（會印出你剛剛填的東西）：

```bash
git config --global --list
```

### 1-3 推上去

**先確認位置，這一步不要跳過：**

```bash
cd ~/Downloads/paynav-taiwan && pwd && ls package.json
```

必須同時看到「路徑結尾是 `/paynav-taiwan`」和「印出 `package.json`」。沒看到就停下來，不要執行下一段。

> 為什麼要確認：如果 `cd` 打錯（例如把 `Downloads` 打成 `Download`），而你又一次貼了多行指令，`git init` 就會建在你的家目錄，`git add .` 會開始掃整個系統，畫面會噴出一堆 `Library/...: Operation not permitted`。發生了就按 `control + C`，然後執行 `rm -rf ~/.git` 清掉（只刪 git 的追蹤資料夾，不動你的檔案）。

確認無誤後，一次貼這段：

```bash
git init && git add . && git commit -m "第一版：台灣支付導航 MVP" && git branch -M main && git remote add origin https://github.com/你的帳號/paynav-taiwan.git && git push -u origin main
```

**這裡用 `&&` 串接是刻意的**：意思是「前一步成功才做下一步」，任何一步失敗就自動停住，不會像分行貼那樣一路錯下去。

第一次 push 會跳出瀏覽器要你登入 GitHub 授權，照著點完就好。

**確認成功**：重新整理 GitHub 頁面，應該看得到 `src`、`public`、`docs` 這些資料夾。

**常見錯誤：**

| 訊息 | 解法 |
| --- | --- |
| `nothing to commit, working tree clean` | 已經 commit 過了，從 `git branch -M main && ...` 接下去跑就好 |
| `remote origin already exists` | `git remote remove origin` 之後重跑 |
| `failed to push some refs` | GitHub 上的 repo 不是空的（建立時勾了 README）。刪掉重建一個空的 |

## 步驟 2：接上 Cloudflare Pages

### 2-1 註冊 Cloudflare

到 <https://dash.cloudflare.com/sign-up> 註冊，免費方案就夠。

### 2-2 建立 Pages 專案

1. 左側選單 → **Workers & Pages** → **Create** → 切到 **Pages** 頁籤
2. 點 **Connect to Git** → 授權 GitHub → 選 `paynav-taiwan`
3. 建置設定照這樣填：

| 欄位 | 填什麼 |
| --- | --- |
| Project name | `paynav-taiwan` |
| Production branch | `main` |
| Framework preset | `Vite`（沒有就選 None） |
| Build command | `npm run build` |
| Build output directory | `dist` |

4. 按 **Save and Deploy**

等 2 到 3 分鐘，成功後會給你一個網址：`https://paynav-taiwan.pages.dev`

**用手機打開這個網址**，這時候定位就會正常運作了。Safari 按分享鍵 →「加入主畫面」→ 之後就是全螢幕 App。

### 2-3 之後怎麼更新

Cloudflare Pages 接上 GitHub 之後，**你每次 `git push`，它就自動重新部署**，不用做任何事。約 2 分鐘生效。

## 步驟 3（選用）：改用 GitHub Actions 部署

如果你希望部署前先自動檢查型別和回饋規則有沒有壞掉，就用專案裡附的 `.github/workflows/deploy.yml`。

要先給它 Cloudflare 的鑰匙：

### 3-1 拿到 Cloudflare 的 API Token 和 Account ID

**Account ID**：Cloudflare 後台 → Workers & Pages → 右側欄「Account ID」，複製那串英數字。

**API Token**：
1. 右上角頭像 → **My Profile** → **API Tokens** → **Create Token**
2. 選 **Edit Cloudflare Workers** 樣板 → Continue
3. Account Resources 選你的帳號，Zone Resources 選 All zones
4. 建立後**立刻複製那串 token**，關掉就看不到了

### 3-2 存進 GitHub

到你的 repo → **Settings** → 左側 **Secrets and variables** → **Actions**

在 **Secrets** 頁籤按 **New repository secret**，加兩筆：

| Name | Secret |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | 剛剛複製的 token |
| `CLOUDFLARE_ACCOUNT_ID` | 你的 Account ID |

> Secrets 存進去之後連你自己都看不到內容，只能覆蓋。這是正常的。

### 3-3 如果同時開了 Pages 自動部署

Cloudflare Pages 的 Git 連結和 GitHub Actions 會重複部署兩次。二選一：
- 想用 Actions（有檢查）→ 到 Pages 專案 Settings → Builds & deployments → 關掉 automatic deployments
- 想簡單→ 直接刪掉 `.github/workflows/deploy.yml`

---

## 步驟 4（選用）：綁自己的網域

1. Cloudflare 後台 → Pages 專案 → **Custom domains** → **Set up a domain**
2. 輸入你的網域（要先在 Cloudflare 或其他註冊商買）
3. 照畫面指示加 CNAME 紀錄，等 DNS 生效（通常 5 分鐘內）

HTTPS 憑證 Cloudflare 會自動處理，不用管。

## 附錄：改用 GitHub Pages

GitHub Pages 也是免費且有 CDN，缺點是網址會多一層路徑，而且和 R2 / Workers 不同平台，設定要多繞一點。

1. `vite.config.ts` 最上面的 `defineConfig({` 之後加一行 base：

```ts
export default defineConfig({
  base: '/paynav-taiwan/',   // 換成你的 repo 名稱
  plugins: [ ... ],
```

2. 新增 `.github/workflows/gh-pages.yml`：

```yaml
name: 部署到 GitHub Pages
on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: npm
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
    steps:
      - uses: actions/deploy-pages@v4
```

3. repo → Settings → Pages → Source 選 **GitHub Actions**

網址會是 `https://你的帳號.github.io/paynav-taiwan/`。

> **注意**：改了 `base` 之後，本機 `npm run dev` 的網址也會變成 `http://localhost:5173/paynav-taiwan/`，這是正常的。
